MAP Advisor Architecture

Hub-and-spoke multi-agent orchestrator with 6 production guardrails

Hub-and-Spoke Flow

  • • User query enters via CLI (Frontend)
  • • Orchestrator owns Date Authority & Disambiguation
  • • Routes to 1 of 3 Specialists (Capacity/Cost/Reliability)
  • • Specialists hard-route date/scope back to Orchestrator
  • • Drafts labeled & scrubbed before return

6 Guardrails (Applied Everywhere)

  • • Date Authority — Orchestrator owns dates
  • • Disambiguation — One clarifying question
  • • Anti-Hallucination — Scrub + Draft label
  • • PII Policy — Accept, Redact, Never Request
  • • Loop-Break — Max 2 routing hops
  • • Scope Restriction — Hard-route out-of-scope

LLM-Agnostic via Abstraction

  • • MockLLMClient — deterministic, zero cost
  • • OpenAIClient — any OpenAI-compatible API
  • • Pluggable — add Anthropic, vLLM, Ollama...
  • • No SDK imports in agents (LLMClient protocol)
